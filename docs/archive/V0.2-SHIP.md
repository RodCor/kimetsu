# Kimetsu v0.2 — Ship Notes

**Tag**: `v0.2-rc1` (commit `09ba266` on `main`)
**One-line**: kimetsu wraps Claude Opus 4.7 as a budget-controlled
coding agent at ~5% of bare Claude Code's cost on Terminal-Bench 2,
with a curated-memory brain that beats no-brain on accuracy at
$0.19/win — 13× cheaper than bare CC per successful task.

**Post-rc1 update (MP-14)**: commits `af105ba` + `3dafad4` widened
the kimetsu tool surface from 7 to **15 tools** — Edit/MultiEdit-style
`edit_file`, Codex-style `apply_patch`, parallel `tool_calls`
envelope, `read_file` offset/limit slice, `glob`, `multi_read`,
`plan`, `think`, typed `move_file` / `delete_file`. The MP-14d
gauntlet (`MP-14-RESULTS.md`) hit **brain = 7/16 = 0.4375** — the
first clean brain > no-brain margin in any v0.2 run, closing the
brain-vs-bare-CC gap from -18.75pp to **-12.5pp** at **$0.19/win**.
The no-brain leg held at exactly 0.375 for the **third straight
run**, locking gate 3 as a true bullseye.

## What v0.2 delivers

- **Harbor / Terminal-Bench integration end-to-end** (MP-7 through
  MP-9). `harbor run --agent-import-path
  kimetsu_harbor.kimetsu_agent:KimetsuAgent` drives the kimetsu
  binary inside Harbor's container; the model emits JSON envelope
  tool calls; kimetsu routes each as a `tool.exec` JSON-RPC frame
  to Harbor's `environment.exec`; the verifier scores.
- **Human-curated memory pipeline** (MP-5 / MP-6). Replaces v0.1's
  auto-accept policy with `kimetsu brain memory review` for
  interactive curation + `memory top` / `memory prune` for
  usefulness-driven hygiene.
- **7-tool composed surface in Rust** (MP-12). `read_file`,
  `list_files`, `search_files`, `write_file`, `git_status`,
  `git_diff`, `shell_command` — each implemented as a composed
  shell call through `HarborShellExecutor`. The model sees
  first-class JSON tools; under the hood every operation routes as
  a tool.exec JSON-RPC frame.
- **Harness improvements** (MP-13 a/b/c/d). Auto-orient the model
  with one shell call before the first turn (saves 3-5 orientation
  turns per task); turn budget 25→40; Claude Code `--max-turns`
  8→16; persistence gate that nudges the model when it tries to
  finish after fewer than 3 tool calls.
- **Resilient claude_code provider** (MP-13f). Retry on transient
  Anthropic 5xx errors (≥500 status or "Overloaded" sentinel) with
  5s/10s exponential backoff. MP-13e caught a 14-of-16 trial
  catastrophic outage that retry fully absorbed in MP-13g.
- **MP-14: widened tool surface** (commits `af105ba` + `3dafad4`).
  Tool catalog 7 → **15**. New tools: `edit_file` (CC Edit +
  MultiEdit equivalent — hash-checked in-place replace, single or
  batched edits), `apply_patch` (Codex-style unified diff,
  multi-file in one call), `read_file` `offset/limit` slice (token-
  cost lever for big files), `glob` (path-pattern file-find;
  complement to `search_files` content grep), `multi_read` (batch
  N reads, up to 25 files per call), `move_file` / `delete_file`
  (typed file ops with workspace-path safety), `plan` (CC-style
  todo list across turns), `think` (no-I/O deliberation slot).
  Parallel `tool_calls` envelope lets the model batch independent
  tool calls in a single turn. MP-14d gauntlet measured the
  cumulative effect — see "post-rc1 update" above.

## V0.2 falsifiable claim — gate-by-gate

The V0.2-PLAN.md ship criteria, state as of MP-14d:

1. **kimetsu-brain ≥ kimetsu-no-brain on Terminal-Bench accuracy** —
   ✓ **passes cleanly (post-MP-14d)** at 0.4375 vs 0.375 — **+1
   win, +6.25pp**. Prior MP-13g was an exact tie. MP-14d is the
   first kimetsu run with a clean brain margin: brain unlocks
   `overfull-hbox` and defeats an Anthropic AUP refusal on
   `break-filter-js-from-html` that no-brain hit at the same
   prompt, while losing `build-pov-ray` (within n=16 variance).
   Net +2/-1.

2. **kimetsu-no-brain within 5pp of bare Claude Code** —
   ✗ **still fails on no-brain** at -18.75pp (0.375 vs bare's
   0.5625). The MP-14 wider tool surface did not move the
   no-brain win count (third run at exactly 0.375 — see gate 3).
   **But brain closes to -12.5pp** (0.4375 vs 0.5625), the best
   gate-2 gap any kimetsu configuration has posted. Remaining
   gap dominated by 600s claude_code timeouts on hard tasks
   (`circuit-fibsqrt`, `dna-assembly`, `caffe-cifar-10`) and
   intermittent AUP refusals — MP-15+ work.

3. **Three consecutive runs within ±5pp** —
   ✓ **passes — bullseye on no-brain**. MP-10 + MP-13 + MP-14d
   no-brain all at exactly 0.375 (6/16) on identical 16 tasks
   across three independent runs days apart. Variance: 0.00pp.
   Brain leg now also tightening: MP-13g 0.375, MP-14d 0.4375
   (range 6.25pp).

**v0.2 ships on gates 1 + 3 with gate 2 partially closed by
brain.** Gate 1 strengthens from MP-13g's tie to MP-14d's clean
margin; gate 3 confirms with a third identical no-brain data
point; gate 2's brain-side gap shrinks from -18.75pp to -12.5pp.

## Cost asymmetry — the actual v0.2 value prop

Bare Claude Code on the same 16 tasks costs **$22.24**. Kimetsu-brain
(MP-14d) costs **$1.36** — a **16× cost reduction** at **78%
relative accuracy** (up from MP-13g's 67%). For the tasks kimetsu
wins, $/win comes in at **$0.19** vs bare's $2.47 — a **13× cheaper
win**. The brain leg is also 36% cheaper than its own no-brain leg
($1.36 vs $2.12) while winning one more task. This is the
MEMORY-USEFULNESS.md Scenario-2 prediction holding cleanly: similar
accuracy on the right tasks, **much** cheaper, and the relative-
accuracy ratio has now been climbing for three releases (MP-10
67% → MP-13g 67% → MP-14d 78%).

## Architectural decisions, recorded

- **External Python adapter** (option A in V0.2-PLAN MP-7).
  `kimetsu_harbor` is Python glue around the dedicated
  `kimetsu-harbor-agent` benchmark binary; the regular `kimetsu`
  CLI stays product-facing.
- **Envelope grammar in the user message, not system prompt** (MP-9).
  Claude Code 2.x's `-p` mode injects its own agentic harness over
  `--system-prompt`; the user message is the only authoritative
  place for our tool grammar.
- **Composed Rust tools, not direct shell** (MP-12). Each tool is a
  Rust shim that builds 1-2 shell calls through HarborShellExecutor
  and returns structured JSON. The model never sees the underlying
  bash, which cuts both token cost and "wrong flag" failure modes.
- **Brain mode as a curated-memory feature, not auto-accept** (MP-5).
  The MP-4 verdict killed auto-accept; v0.2 ships the
  `kimetsu brain memory review` human-curation flow with a project
  pointed at by `--project` / `$KIMETSU_HARBOR_PROJECT`.

## What's NOT in v0.2 (deferred)

- Closing the no-brain bare-CC accuracy gap (-18.75pp). MP-14
  widened the tool surface 7→15 but the no-brain leg held at
  exactly 0.375 for three straight runs; the gap is not
  tool-surface-limited anymore. Remaining drivers: 600s
  claude_code timeouts on hard tasks (`circuit-fibsqrt`,
  `dna-assembly`, `caffe-cifar-10`) and intermittent Anthropic
  AUP refusals on specific prompts. Both addressed in MP-15.
- Per-task instruction-aware memory selection. Currently memories
  are retrieved by query string against the task description; a
  task-type classifier could pick more relevant capsules.
- v0.2 stability over a full week per V0.2-PLAN literal text. We
  have three same-day runs at exactly 0.375; running the bench
  daily for a week and recording variance is straightforward but
  hasn't been done — MP-15.

## How to use v0.2

```bash
# One-time setup (see kimetsu_harbor/SETUP-WSL.md for full WSL2 path)
pip install harbor
cargo build -p kimetsu-cli -p kimetsu-harbor-rs --release

# Curate a memory pool
kimetsu init
kimetsu brain memory add --scope global_user --kind preference "..."
kimetsu brain memory review               # interactive review of proposals
kimetsu brain memory top --min-uses 3     # see what's pulling weight
kimetsu brain memory prune --apply        # clean up underperformers

# Run Terminal-Bench (brain mode)
export KIMETSU_HARBOR_BIN=$(pwd)/target/release/kimetsu-harbor-agent
export KIMETSU_HARBOR_PROJECT=$(pwd)
harbor run \
  -d terminal-bench/terminal-bench-2 \
  --agent-import-path kimetsu_harbor.kimetsu_agent:KimetsuAgent \
  -n 2 -k 1 --yes
```
